☁️ Cloud Sync + Play Store রোডম্যাপ

1
Netlify-তে ফ্রি host করুন
netlify.com → New Site → GitHub থেকে deploy
2
Firebase যোগ করুন (ফ্রি)
firebase.google.com → Firestore → keys বসান
3
PWA বানান
manifest.json + service worker যোগ করুন
4
Play Store submit করুন
TWA দিয়ে $25 দিয়ে publish করুন

✅ Web app update করলেই সব user স্বয়ংক্রিয়ভাবে আপডেট পাবে!
